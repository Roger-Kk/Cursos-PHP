# PHP

Repositório para aprendizado de PHP. Cursos Alura PHP.

Cada pasta corresponde a um curso, com arquivos contendo código PHP para seu devido fim.
📖 **[Ver os exemplos e como rodar cada um](https://roger-kk.github.io/Cursos-PHP/)**

## Conceitos iniciais

- `PHP Conceitos I - Dados e loops/` — variáveis, condicionais (`if`), laços (`for`/`while`) e desafios práticos.
- `PHP Primeira Aplicação/` — projeto inicial para dar os primeiros passos.
- `PHP Criando sua aplicação/` — construção de uma aplicação (`screenMatch.php`) com desafios ao longo do caminho.

## Organização e orientação a objetos

- `PHP Organize seu código/` — separação entre `public/` e `src/`, importação de dados a partir de `filme.json` e instruções para subir o servidor web.
- `PHP Orientação a Objetos/` — classes, objetos e métodos, organizados em `src/`.
- `PHP Herança e Interfaces/` — herança, interfaces, autenticação, autoload, acesso a banco e cálculo de bonificações.
- `PHP Interface, Traits e Erros/` — traits, exceções e tratamento de erros, com o projeto `screen-match/`.

## Arquitetura e boas práticas

- `PHP Padrão MVC/` — arquitetura Model-View-Controller com `config/`, `src/`, `views/` e dependências gerenciadas pelo Composer.
- `PHP Boas Práticas/` — aplicação com a mesma estrutura MVC, focada em convenções e qualidade de código.

## Dependências e banco de dados

- `PHP Composer/` — gerenciamento de dependências com `composer.json` e `composer.lock`, consumindo pacotes externos.
- `PHP Banco de Dados/` — integração com SQLite (`banco.sqlite`): conexão, criação de turma, inserção, listagem e remoção de alunos.
