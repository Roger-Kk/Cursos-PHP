Cursos PHP

Exemplos do repositório, com o passo a passo para rodar cada um. Alguns abrem direto no navegador; outros precisam rodar na sua máquina, porque dependem do interpretador PHP.

Antes de começar

  1. Instale o PHP. Baixe em php.net/downloads. Para conferir se funcionou, abra o terminal e rode: 
    php -v
    Se aparecer a versão, está pronto. Se der "comando não encontrado", o PHP não está no PATH — reinstale marcando a opção de adicionar ao PATH.
  2. Baixe o repositório. Copie tudo para o seu computador com: 
    git clone [github.com](https://github.com/Roger-Kk/Cursos-PHP.git)
cd Cursos-PHP
    Sem Git instalado? Use o botão verde Code → Download ZIP e descompacte.
  3. Entre na pasta do exemplo. Cada bloco abaixo mostra o comando de terminal para entrar na pasta certa. Os nomes têm espaços, então vão entre aspas: 
    cd "PHP Padrão MVC"
    O terminal precisa estar sempre na pasta que contém o arquivo composer.json.
  4. Instale as dependências. Só é necessário nos exemplos que usam Composer (os marcados como rodar localmente): 
    composer install
    Se não tiver o Composer, instale em getcomposer.org. A pasta vendor/ já está no repositório, mas rodar o composer install garante que tudo esteja no lugar.
  5. Inicie o servidor. Servidor embutido do PHP, apontando para a pasta pública do projeto: 
    php -S localhost:8000 -t public
    Depois abra localhost:8000 no navegador. Para parar, use Ctrl+C no terminal.

    Se a pasta for public/, use -t public. Se o projeto não tiver essa pasta, aponte para a raiz: php -S localhost:8000.

Exemplos rodando no GitHub Pages

PHP Padrão MVC

PHP Padrão MVC/ abre no navegador

Arquitetura Model-View-Controller com config/, src/ e views/.

Para gerar a versão estática

  1. No terminal: cd "PHP Padrão MVC"
  2. Instale as dependências: composer install
  3. Suba o servidor: php -S localhost:8000 -t public
  4. Abra localhost:8000, confira a página
  5. Salve o HTML gerado (no navegador: Ctrl+S) dentro de docs/mvc/

Resultado publicado

mvc/index.html

PHP Conceitos I - Dados e loops/ rodar localmente

Variáveis, condicionais e laços. Arquivos: variaveis.php, if.php, for_while.php e desafios.php.

PHP Banco de Dados

PHP Banco de Dados/ rodar localmente

Integração com SQLite (banco.sqlite): conexão, criação de turma e CRUD de alunos.

Como rodar

cd "PHP Banco de Dados"
composer install
php criarTurma.php
php inserirAluno.php
php listaAlunos.php

Esses scripts alteram o arquivo banco.sqlite. Para desfazer mudanças, restaure o arquivo com git checkout banco.sqlite. O removerAluno.php apaga registros.

O GitHub Pages executa apenas arquivos estáticos, por isso os exemplos com PHP aparecem aqui como instruções e não como páginas interativas. Para vê-los rodando, use o servidor embutido na sua máquina — é o mesmo comando php -S mostrado acima.
